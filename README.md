# -AI-skills
在学习，工作过程中迷茫过 人与AI边界的问题，困惑AI时代应该学些什么 ？
在ai讨论中，参考一些知识博主的理论，总结启发学习路径的skills。 

旨在：帮助完成了解（指令投喂）—熟悉（质检查错）—掌握（系统建构），并且辅助实战场景。
	学疏才浅，有修改优化建议欢迎提出
分别定位
 	通用职场与业务场景 VS 游戏研发工程（程序/TA/管线/性能/品质等）

触发关键词
两版都含：想学习、学习路径（因此仅说「想学习」时，系统可能要在两版里二选一，最好在句子里带领域词）。
通用版额外常用： 生成学习路径、AI学习规划、重构认知、人机协同架构
游戏版额外常用： 游戏学习路径、游戏工程架构、开发协同方案、建立游戏研发管线
